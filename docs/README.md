# Docs

This folder contains ApyGuard benchmark design documents and project conventions.

Files:

- `apyguard-api-benchmark-cases.md`
  Canonical implemented benchmark catalog and OWASP coverage summary
- `apyguard-api-benchmark-cases.yaml`
  Structured benchmark index derived from implemented benchmark metadata
- `auth-first-benchmark-pattern.md`
  Required auth-first convention for API benchmarks

Use these documents when adding new `APY-*` benchmarks so the suite stays internally consistent.
