# Support

## Getting Help

For usage questions and benchmark authoring guidance:

- Open a GitHub issue in this repository.
- Include benchmark ID, exact commands, and relevant logs.

## Security-Related Reports

Do not open public issues for sensitive security concerns in repository infrastructure.

Use the process described in `SECURITY.md`.

## Scope Reminder

Application vulnerabilities inside benchmark services are intentional by design.
Please report only framework/repository issues, not benchmark challenge vulnerabilities.
